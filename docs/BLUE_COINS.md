# Blue Coins list

Index refers to the bit in a binary byte

```
Index:  7 6 5 4 3 2 1 0
        ---------------
Binary: 0 0 0 0 0 0 0 0

Ex: Bit enabled at index 2 and 4 would be: 00010100
```
