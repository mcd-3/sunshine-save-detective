# Blue Coins list

Index refers to the bit in a binary byte

```
Index:  0 1 2 3 4 5 6 7
        ---------------
Binary: 0 0 0 0 0 0 0 0

Ex: Bit enabled at index 3 and 5 would be: 00010100
```
